# ELISN LAB (테스트베드)

> ELISN에 넣을 기능을 먼저 시험하는 곳이에요. 여기서 써 보고 괜찮은 것만 운영 사이트로 옮겨요.
> 운영 사이트: **https://udinotti.github.io/elisn/**

화면 맨 위 노란 줄의 "패치 내역"에서 무엇이 바뀌었는지 볼 수 있어요. 시험 중이라 갑자기 바뀌거나 잠깐 안 될 수 있어요.

## 이런 걸 할 수 있어요

| | |
|---|---|
| 📅 **허가일로 거르기** | 건축허가일을 넣으면 그날 적용되는 조항만 남기고, 적용 안 되는 조항은 따로 모아 보여 줘요 |
| 🔎 **낱말·조항 번호 검색** | "비상조명", "5.1.2"처럼 낱말이나 번호로 찾아요 |
| 🗂️ **시기별 나란히** | 같은 조항이 시기(체계)마다 어떻게 달랐는지 칸을 나란히 놓고 봐요 |
| 🔁 **시기별 비교** | 바뀐 낱말에 밑줄을 그어 옛 글과 새 글을 비교해요 |
| 📜 **원문 보기** | 조항마다 근거 고시 원문을 붙였어요. 허가일을 넣으면 그날 시행 중이던 판으로 보여 줘요 |
| 🏷️ **개정 표시** | 허가일 전에 개정·신설된 조항을 표시하고, 개정일별로 골라 볼 수 있어요 |
| 🛗 **승강기 종류** | 엘리베이터, 에스컬레이터·무빙워크, 수직형·경사형 휠체어리프트, 소형화물용·경사형 엘리베이터 |
| 📘 **표준화 자료** | 검사기준과 함께 표준화 자료도 찾아요 |
| ⭐ **즐겨찾기** | 자주 보는 조항을 별표해 두고 모아 봐요 |
| 🖨️ **인쇄·공유** | 결과를 인쇄·PDF로 저장하거나, 지금 화면 그대로 링크로 보내요 |
| 📱 **폰으로 보기** | PC 화면에 뜬 QR을 폰으로 찍으면 같은 결과가 폰에서 열려요 |
| ✈️ **인터넷 없이** | 한 번 열어 두면 인터넷이 없는 현장에서도 열려요. 홈 화면에 추가해 앱처럼 쓸 수 있어요 |

## 담긴 자료

- 검사기준 조항 **5,200여 개** (엘리베이터 2,000여 개, 그 밖의 종류 3,200여 개)
- 표준화 자료 **290여 개**
- 조항 그림 **186장**
- 근거: [국가법령정보센터](https://www.law.go.kr)에 공개된 행정안전부 고시 (승강기 검사기준, 승강기 안전기준 등)

## 쓰는 법

1. 위쪽에서 승강기 **종류**를 골라요.
2. **건축허가일**을 넣거나 "바로 고르기"에서 날짜를 눌러요.
3. 찾을 **낱말**이나 조항 번호를 넣어요. 비워 두면 전체를 보여 줘요.
4. 조항 카드의 **원문 보기**로 고시 원문을, **시기별 비교**로 시기마다 달라진 글을 봐요.

## 알아 두세요

- **참고용**이에요. 실제 판단은 꼭 고시 원문으로 확인하세요.
- 틀린 곳이나 바라는 점은 화면의 **의견 보내기** 버튼으로 알려 주세요.
